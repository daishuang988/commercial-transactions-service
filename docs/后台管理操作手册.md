## 一、登录

- 打开管理端地址，用管理员账号密码登录。
- 管理员账号由超级管理员在「权限管理 → 账户管理」中创建和分配。
- 登录后看到的菜单，取决于该账号所属角色的权限。
- 当前用户初始密码统一为 `123456`，用户登录后可自行修改，后台也可以帮用户重置。

## 三、用户管理

### 3.1 用户列表

- 支持按手机号 / 昵称搜索、分页。
- 导出 Excel：用户下单统计表（昵称、卖货金额、买货金额、差额、推广人）。

### 3.2 编辑用户

| 项目 | 说明 |
|---|---|
| 昵称 | 用户显示名字 |
| 手机号 | 登录账号 |
| 等级 | 普通用户 / 推荐人 / 店长 / 二代店长，四选一 |
| 每日可抢单数 | 该用户每天最多能抢的单数，每天 0 点重置；填 0 表示不能抢单。**新注册用户默认 0，需要配置后才能抢单** |
| 优先用户 | 是 = 优先抢购用户，按系统设置的优先规则提前进场抢购 |
| 允许寄卖 | 该用户是否可以把买到的商品寄卖 |
| VIP 时间 | 会员有效期 |
| 账号状态 | 正常 / 冻结（冻结后无法登录） |
| 密码 | 重置密码，至少 6 位 |

### 3.3 冻结 / 解冻

列表上快捷操作。冻结后用户无法登录。

### 3.4 修改上级

调整用户的推荐人（影响推荐关系和推广奖励归属）。

### 3.5 充值 / 扣减

| 项目 | 说明 |
|---|---|
| 资产类型 | 余额 / 优惠券 / 个人奖金 / 推广奖金，四选一 |
| 操作 | 增加 / 扣减 |
| 金额 | 正数，两位小数 |
| 备注 | 会显示在用户的对应明细里 |

### 3.6 合同

- **上传合同**：代替用户录入已签署的合同。
- **重置合同**：清除用户合同。用户没有合同时，用户端不显示钱包数据。

### 3.7 批量删除 / 导出

- 批量删除：按条件批量删除用户，危险操作，谨慎使用。
- 导出：用户下单统计表。

## 四、订单管理

### 4.1 订单列表

- 筛选：状态（待付款 / 已支付 / 已完成）、是否已寄卖、下单时间范围。
- 搜索：订单号、手机号等。
- 支持导出。

### 4.2 订单详情

展示买卖双方、商品信息、金额、收货信息、支付截图，以及下单 / 支付 / 确认收货时间。

### 4.3 修改订单状态

管理员可手动修改订单状态。

### 4.4 兑换订单

寄卖金额达到系统设置的拆分阈值时，一笔寄卖自动拆成的多笔兑换订单，只读查看。

---

## 五、商品管理

### 5.1 商品分类

商城商品分类的新增、编辑（重名会提示）、删除、排序。

### 5.2 商品管理（商城自营商品）

- 新增 / 编辑：标题、图片、价格、分类、库存。
- 上架 / 下架、删除。
- 支持状态、分类筛选和标题搜索。

> 商城自营商品和用户寄卖商品是两个独立列表，互不影响。

### 5.3 寄售商品（用户寄卖的商品）

| 项目 | 说明 |
|---|---|
| 状态 | 待售 / 已售 |
| 显示 | 显示 / 隐藏。**用户端售卖列表只显示「待售 + 显示」的商品**，隐藏后用户端看不到 |

支持的操作：

- 新增（手动录入寄售商品）、编辑、删除。
- 状态筛选（待售 / 已售）、日期筛选、标题搜索。
- 上下架：把商品改为待售或已售；隐藏：把商品从用户端售卖列表移除。

### 5.4 秒杀列表

秒杀活动事件的查看与新增。

## 六、提现管理

### 6.1 提现状态

| 状态 | 说明 |
|---|---|
| 待处理 | 用户刚申请，等待审核 |
| 已通过 | 已打款 |
| 已驳回 | 已拒绝 |

### 6.2 审核操作

- **通过**：表示已打款。
- **驳回**：系统自动把提现金额原路退回用户账户（优惠券退回优惠券、推广奖金退回推广奖金），并记录流水。
- 只能操作「待处理」的提现，已处理过的会提示"该提现已处理过"。

### 6.3 筛选与导出

按提现编号 / 货币类型 / 账号 / 状态 / 时间筛选，支持导出 Excel。

### 6.4 提现开关

用户能否发起提现，由系统设置里的「优惠券提现开关」「推荐奖提现开关」控制，开关关闭时用户端无法提现。

## 七、数据明细

四个页面：余额明细、优惠券明细、个人奖金明细、推广奖金明细。

- 每条记录包含：用户、收入 / 支出、金额、变动前后余额、备注、时间。
- 均支持按手机号搜索、时间筛选、导出 Excel。
- 个人奖金（静态收益）和推广奖金（直推奖励）的流水来自系统每日自动结算（每晚 23:59 执行）。

## 八、商城设置

### 8.1 系统设置

保存即生效，分五组：

**基础设置**

| 项目 | 说明 |
|---|---|
| 站点名称 | 站点显示名字 |
| 系统公告 | 用户端显示的公告内容 |
| 客服电话 | 用户端展示的客服电话 |

**秒杀规则**

| 项目 | 说明 |
|---|---|
| 抢购开放日期 | 周几开放抢购 |
| 抢购开始 / 结束时间 | 每天抢购的时间段 |
| 优先抢购最多单数 | 优先用户在优先窗口内的上限单数 |
| 优先抢购提前分钟数 | 优先用户提前多少分钟进场抢购 |

**交易规则**

| 项目 | 说明 |
|---|---|
| **商城抢购开关** | ⚠️ 交易总开关。关闭后用户端不能抢购、不能购买寄售商品 |
| 寄卖加价比例 | 商品每轮寄卖的增值比例 |
| 店长收益比例 | 店长的分佣比例 |
| 直推收益比例 | 推荐人拿的直推奖励比例 |
| 静态收益比例 | 买家每天拿的静态收益比例 |
| 抢单奖励比例 | 抢单奖励比例 |
| 上架手续费比例 | 寄卖上架时扣的手续费比例 |
| 寄卖截止时间 | 超过这个时间点后不能再寄卖 |
| 寄卖指定商品 | 寄卖锁定哪个商品 |
| 抢购页面商品 | 抢购页展示的商品配置 |
| 拆分阈值 | 寄卖金额达到多少时自动拆成多笔兑换订单 |

**功能开关**

| 项目 | 说明 |
|---|---|
| 短信校验 | 关：不真发短信（验证码固定）；开：走真实短信发送 |
| 优惠券提现开关 | 关：用户不能提优惠券 |
| 推荐奖提现开关 | 关：用户不能提推广奖金 |

**协议内容**

- 用户协议、购买委托代卖协议、购买须知、备用协议、合同内容。
- 前四个是用户端对应协议页的内容；合同内容为合同签署页的 PDF 地址。

### 8.2 首页轮播图 / 广告图

- 上传图片、排序、启用 / 停用、批量删除。

### 8.3 个人资料

管理员自己的信息和修改密码。

## 十、运营要点（日常必知）

1. **新注册用户默认不能抢单**（每日可抢单数为 0），需要在「用户管理 → 编辑」里配置后才能抢。
2. 用户每天的抢购次数在 **0 点自动重置**。
3. 系统**每晚 23:59 自动结算**：给已完成订单的买家发放收益，进入其个人奖金 / 推广奖金。
4. **合同**：用户要先签合同，用户端才显示钱包数据；没有合同可以联系运营在后台上传。
5. **提现**：用户申请 → 后台「待处理」→ 通过（打款）或驳回（自动退款）。前提是系统设置里打开了对应的提现开关。
6. **冻结**：冻结后用户无法登录、无法交易。
7. **用户端售卖列表**只显示「待售 + 显示」的寄售商品。

## 十一、常见操作速查

| 想做什么 | 怎么做 |
|---|---|
| 让某个用户能抢单 | 用户管理 → 编辑 → 每日可抢单数填具体数字（如 5） |
| 让某个用户不能抢单 | 编辑 → 每日可抢单数填 0 |
| 给用户加资产 | 用户管理 → 该用户 → 充值 → 选资产类型 → 增加 → 填金额和备注 |
| 帮用户改密码 | 编辑 → 密码（至少 6 位）→ 保存 |
| 冻结 / 解冻用户 | 用户列表上的快捷操作 |
| 停掉整个商城交易 | 商城设置 → 系统设置 → 商城抢购开关关闭 |
| 审批提现 | 提现管理 → 待处理 → 通过（打款）或驳回（自动退钱） |
| 隐藏某件寄售商品 | 商品管理 → 寄售商品 → 显示改为隐藏 |
| 把已售商品改回待售 | 寄售商品 → 状态改为待售 |
| 发公告 | 商城设置 → 系统设置 → 系统公告 |
| 换首页轮播图 | 商城设置 → 首页轮播图 → 新增 / 编辑 |
| 调整抢购时间 / 规则 | 商城设置 → 系统设置 → 秒杀规则 |
| 查某个用户的收益流水 | 数据明细 → 对应页面 → 搜索手机号 |
| 导出用户 / 提现 / 流水 | 对应页面的导出按钮（Excel） |
| 加管理员账号 | 权限管理 → 账户管理 → 新增 |
